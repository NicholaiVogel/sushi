# sushi

Experimental WebMCP Challenge app. The canonical product and architecture spec lives in [SPEC.md](./SPEC.md).

## Stack

- Astro
- React islands
- `@json-render/core`
- `@json-render/react`
- `webmcp-types`
- Cloudflare Pages target

## Commands

```sh
bun install
bun run dev
bun run build
bun run preview
```
